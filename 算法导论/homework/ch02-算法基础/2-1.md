## 2.1-3

(1) 伪代码

```
FIND_V(A, v)
    key = v
    idx = -1
    v = NIL
    for i = 1 to A.length
        if A[i] == key
            v = key
            idx = i
            break
    return v, idx
```  

(2) 循环不变式

不变式：如果idx不在[1,A.length]范围内，则v=NIL；否则v=A[idx]

- 初始化：在for循环开始前，index=-1，不在范围内，且v=NIL；不变式成立
- 保持：每次循环前如果条件保持的话（必须保证不变式的前半部分性质成立才能进入循环），则进入循环后，
    - 如果if条件成立，则idx被赋予i值，而A[i]==key；v被赋予key值，不变式仍然成立；执行break进入终止
    - 如果if条件不成立，idx和v没有被修改，因此不变式仍然成立
- 终止：循环终止时，不变式成立的话，要么idx不在[1,A.length]范围内，即A中没有值等于参数v，v被赋予了NIL；要么idx在[1,A.length]范围内，并且满足A[idx]=v,且v的值没变。因此算法正确
