# 链式法则

**链式法则**的核心定义：如果两个量的变化率已知，则它们通过连锁关系组合起来之后的变化率，等于各自的变化率的乘积

## 1.一元函数链式法则

### 定义

设有有两个函数$y = f(u)$和$u = g(x)$，则它们可以组合成一个复合函数$y = f(g(x))$；如果函数$g$在点$x$处可导，函数$f(u)$在$u=g(x)$处可导，则复合函数$y = f(g(x))$在点$x$处可导。导数的表达式为:

$\frac{dy}{dx} = \frac{dy}{dg}\cdotp \frac{dg}{dx}$


## 2.多元函数的链式法则

### 定义

这里以最常见的二维函数$f(x,y)$来举例。

假设有二元函数$z =f(x,y)$，同时$x$和$y$又是另一个变量$t$的函数$x = g(t)$，$y = u(t)$，则$z$是关于$t$的复合函数$z = f(g(t), u(t))$. 这种情况下，$z$关于$t$的全导数为：

$\frac{dz}{dt} = \frac{\partial{z}}{\partial{x}}\cdotp \frac{dx}{dt} + \frac{\partial{z}}{\partial{y}}\cdotp \frac{dy}{dt}$

更一般的：**对于函数$z=f(x_1, x_2, x_3 ...)$，其中$x_1$，$x_2$...是关于$t$的函数$x_1(t)$，$x_2(t)$...，则$f$关于$t$的全导数为**

$\frac{dz}{dt} = \sum_{i=1}^n\frac{\partial{z}}{\partial{x_i}} \cdot \frac{dx_i}{dt}$

### 例子

设 $z = x^2y + y^3$，其中$x=sin(t)$，$y=cos(t)$。求$\frac{dz}{dt}$.

**解**
$\frac{\partial{z}}{\partial{x}} = 2yx$

$\frac{\partial{z}}{\partial{y}} = x^2 + 3y^2$

$\frac{dx}{dt} = cos(t)$

$\frac{dy}{dt} = -sin(t)$

$\therefore \frac{dz}{dt} = 2yx\cdot cos(t) + (x^2 + 3y^2)\cdot (-sin(t))$

$= 2cos(t)sin(t)cos(t) - (sin^2(t) + 3cos^2(t))sin(t)$
