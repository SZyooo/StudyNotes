# 梯度Gradient

## 定义

对于函数$f(x,y,z...)$，梯度的表达式为

$\nabla f = (\frac{\partial{f}}{\partial{x}}, \frac{\partial{f}}{\partial{y}}, \frac{\partial{f}}{\partial{z}})$

它的数学含义是该函数最大的变化方向。

## 方向梯度

对于指定方向$u(x,y,z...)$，函数$f(x,y,z...)$在该方向上的梯度为函数的梯度和该方向向量（单位）的点积：

$\nabla_u f = (\frac{\partial{f}}{\partial{x}}, \frac{\partial{f}}{\partial{y}}, \frac{\partial{f}}{\partial{z}}) \cdotp u$

> 向量$u$是单位向量
