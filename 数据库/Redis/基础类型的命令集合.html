Redis 基础类型命令全集

涵盖 String、List、Set、Sorted Set、Hash 五种核心数据类型的所有命令

1. String（字符串） 写 读 删

Redis 中最基本的数据类型，最大 512 MB。底层采用动态字符串（SDS），支持自动扩容。
命令语法复杂度说明
SET SET key value [EX|PX|EXAT|PXAT|KEEPTTL] [NX|XX] [GET] O(1) 写设置指定 key 的值。
GET GET key O(1) 读获取指定 key 的值。
GETDEL GETDEL key O(1) 读删获取值后删除该 key（Redis 6.2+）。
GETEX GETEX key [EX|PX|EXAT|PXAT|PERSIST] O(1) 读获取值并同时设置过期时间（Redis 6.2+）。
SETNX SETNX key value O(1) 写key 不存在时设置值（SET if Not eXists）。返回 1 成功，0 失败。
SETEX SETEX key seconds value O(1) 写设置值的同时指定过期时间（秒）。
PSETEX PSETEX key milliseconds value O(1) 写设置值的同时指定过期时间（毫秒）。
MSET MSET key value [key value ...] O(N) 写批量设置多个 key-value。
MGET MGET key [key ...] O(N) 读批量获取多个 key 的值。
MSETNX MSETNX key value [key value ...] O(N) 写所有 key 都不存在时才批量设置（原子性）。
APPEND APPEND key value O(1) 写将 value 追加到原值的末尾，返回追加后长度。
GETRANGE GETRANGE key start end O(N) 读获取字符串的子串（包含 start 和 end，支持负数）。
SETRANGE SETRANGE key offset value O(1) 小值 / O(N) 大值 写从指定偏移开始覆写字符串。
STRLEN STRLEN key O(1) 读返回字符串长度（字节数）。
INCR INCR key O(1) 写原子 +1。
INCRBY INCRBY key increment O(1) 写原子增加指定整数。
INCRBYFLOAT INCRBYFLOAT key increment O(1) 写原子增加指定浮点数。
DECR DECR key O(1) 写原子 -1。
DECRBY DECRBY key decrement O(1) 写原子减少指定整数。
LCS LCS key1 key2 [LEN] [IDX] [MINMATCHLEN len] [WITHMATCHLEN] O(N*M) 读最长公共子串（Redis 7.0+）。
SUBSTR SUBSTR key start end O(N) 读同 GETRANGE（旧版，可能废弃）。

2. List（列表） 写 读 删 阻

基于链表实现，插入 / 删除快（O(1)），索引查找慢（O(N)）。常用于消息队列、最新列表等场景。
命令语法复杂度说明
LPUSH LPUSH key element [element ...] O(1) 每个元素 写从头部（左侧）插入一个或多个元素。
LPUSHX LPUSHX key element [element ...] O(1) 每个元素 写仅当 key 存在时从头部插入。
RPUSH RPUSH key element [element ...] O(1) 每个元素 写从尾部（右侧）插入一个或多个元素。
RPUSHX RPUSHX key element [element ...] O(1) 每个元素 写仅当 key 存在时从尾部插入。
LPOP LPOP key [count] O(N) count 删移除并返回头部一个或多个元素。
RPOP RPOP key [count] O(N) count 删移除并返回尾部一个或多个元素。
RPOPLPUSH RPOPLPUSH source destination O(1) 移移除 source 尾部元素并推到 destination 头部。
LMOVE LMOVE source destination LEFT|RIGHT LEFT|RIGHT O(1) 移原子弹出一个源端元素并推入目标端（Redis 6.2+ 替代 RPOPLPUSH）。
BLPOP BLPOP key [key ...] timeout O(1) 阻LPOP 的阻塞版本，超时返回 nil。
BRPOP BRPOP key [key ...] timeout O(1) 阻RPOP 的阻塞版本。
BRPOPLPUSH BRPOPLPUSH source destination timeout O(1) 阻RPOPLPUSH 的阻塞版本。
BLMOVE BLMOVE source destination LEFT|RIGHT LEFT|RIGHT timeout O(1) 阻LMOVE 的阻塞版本（Redis 6.2+）。
LLEN LLEN key O(1) 读获取列表长度。
LRANGE LRANGE key start stop O(S+N) 读获取范围内元素（start/stop 支持负数）。
LINDEX LINDEX key index O(N) 读通过索引获取元素。
LSET LSET key index element O(N) 写通过索引设置元素值。
LINSERT LINSERT key BEFORE|AFTER pivot element O(N) 写在基准元素前后插入新元素。
LREM LREM key count element O(N) 删移除指定数量的匹配元素（count > 0 从左，< 0 从右，= 0 全部）。
LTRIM LTRIM key start stop O(N) 删裁剪区间外的元素。
LPOS LPOS key element [RANK rank] [COUNT count] [MAXLEN len] O(N) 读查找元素位置（Redis 6.0.6+）。

3. Set（集合） 写 读 删 集

无序、不重复的字符串集合。基于哈希表实现，支持交集、并集、差集运算。适合标签系统、好友关系等。
命令语法复杂度说明
SADD SADD key member [member ...] O(1) 每个元素 写添加一个或多个元素。
SREM SREM key member [member ...] O(1) 每个元素 删移除一个或多个元素。
SMEMBERS SMEMBERS key O(N) 读返回集合所有元素（慎用于大集合）。
SISMEMBER SISMEMBER key member O(1) 读判断元素是否存在。返回 1/0。
SCARD SCARD key O(1) 读获取集合元素数量。
SPOP SPOP key [count] O(1) / O(N) count 删随机移除并返回一个或多个元素。
SRANDMEMBER SRANDMEMBER key [count] O(1) / O(N) count 读随机返回元素（不移除）。count 为正不重复，为负可重复。
SMOVE SMOVE source destination member O(1) 移将元素从 source 原子移到 destination。
SDIFF SDIFF key [key ...] O(N) 集返回第一个集合与其余集合的差集。
SDIFFSTORE SDIFFSTORE destination key [key ...] O(N) 集差集结果存入 destination。
SINTER SINTER key [key ...] O(N*M) 集返回所有集合的交集。
SINTERSTORE SINTERSTORE destination key [key ...] O(N*M) 集交集结果存入 destination。
SUNION SUNION key [key ...] O(N) 集返回所有集合的并集。
SUNIONSTORE SUNIONSTORE destination key [key ...] O(N) 集并集结果存入 destination。
SSCAN SSCAN key cursor [MATCH pattern] [COUNT count] O(1) 每次调用 读增量迭代集合元素。
SMISMEMBER SMISMEMBER key member [member ...] O(1) 每个元素 读批量判断元素是否存在（Redis 6.2+）。
RANDOMKEY RANDOMKEY O(1) 读随机返回一个 key（通用命令，非 Set 专属）。

4. Sorted Set（有序集合 / ZSet） 写 读 删 集

每个元素关联一个 double 类型分数（score），按分数排序。底层使用跳跃表 + 哈希表实现。适合排行榜、延时队列等。
命令语法复杂度说明
ZADD ZADD key [NX|XX] [GT|LT] [CH] [INCR] score member [score member ...] O(log N) 每个元素 写添加或更新元素分数。
ZREM ZREM key member [member ...] O(log N) 每个元素 删移除一个或多个元素。
ZCARD ZCARD key O(1) 读获取有序集合元素数量。
ZCOUNT ZCOUNT key min max O(log N) 读统计分数在 [min, max] 内的元素数。
ZSCORE ZSCORE key member O(1) 读获取元素的分数。
ZINCRBY ZINCRBY key increment member O(log N) 写原子增减元素分数。
ZRANK ZRANK key member O(log N) 读返回元素正序排名（从 0 开始）。
ZREVRANK ZREVRANK key member O(log N) 读返回元素倒序排名。
ZRANGE ZRANGE key start stop [BYSCORE|BYLEX] [REV] [LIMIT offset count] [WITHSCORES] O(log N + M) 读返回指定排名范围内的元素（Redis 6.2+ 增强）。
ZREVRANGE ZREVRANGE key start stop [WITHSCORES] O(log N + M) 读返回倒序排名范围内的元素（旧版，建议用 ZRANGE ... REV）。
ZRANGEBYSCORE ZRANGEBYSCORE key min max [WITHSCORES] [LIMIT offset count] O(log N + M) 读按分数范围返回元素（旧版，建议用 ZRANGE ... BYSCORE）。
ZREVRANGEBYSCORE ZREVRANGEBYSCORE key max min [WITHSCORES] [LIMIT offset count] O(log N + M) 读按分数范围倒序返回（旧版）。
ZRANGEBYLEX ZRANGEBYLEX key min max [LIMIT offset count] O(log N + M) 读按字典序范围返回（同分元素）。
ZREVRANGEBYLEX ZREVRANGEBYLEX key max min [LIMIT offset count] O(log N + M) 读按字典序范围倒序返回。
ZLEXCOUNT ZLEXCOUNT key min max O(log N) 读统计字典序范围内的元素数。
ZREMRANGEBYRANK ZREMRANGEBYRANK key start stop O(log N + M) 删移除指定排名范围内的元素。
ZREMRANGEBYSCORE ZREMRANGEBYSCORE key min max O(log N + M) 删移除指定分数范围内的元素。
ZREMRANGEBYLEX ZREMRANGEBYLEX key min max O(log N + M) 删移除指定字典序范围内的元素。
ZPOPMIN ZPOPMIN key [count] O(log N * M) 删移除并返回分数最小的 N 个元素。
ZPOPMAX ZPOPMAX key [count] O(log N * M) 删移除并返回分数最大的 N 个元素。
BZPOPMIN BZPOPMIN key [key ...] timeout O(log N) 阻ZPOPMIN 的阻塞版本。
BZPOPMAX BZPOPMAX key [key ...] timeout O(log N) 阻ZPOPMAX 的阻塞版本。
ZUNIONSTORE ZUNIONSTORE destination numkeys key [key ...] [WEIGHTS w] [AGGREGATE SUM|MIN|MAX] O(N) + O(log M) 集并集计算并存入 destination。
ZINTERSTORE ZINTERSTORE destination numkeys key [key ...] [WEIGHTS w] [AGGREGATE SUM|MIN|MAX] O(N*K) + O(log M) 集交集计算并存入 destination。
ZUNION ZUNION numkeys key [key ...] [WEIGHTS w] [AGGREGATE SUM|MIN|MAX] [WITHSCORES] O(N) + O(log M) 集并集计算，不存结果直接返回（Redis 7.0+）。
ZINTER ZINTER numkeys key [key ...] [WEIGHTS w] [AGGREGATE SUM|MIN|MAX] [WITHSCORES] O(N*K) + O(log M) 集交集计算，不存结果直接返回（Redis 7.0+）。
ZDIFFSTORE ZDIFFSTORE destination numkeys key [key ...] O(N) + O(log M) 集差集计算并存入 destination（Redis 6.2+）。
ZDIFF ZDIFF numkeys key [key ...] [WITHSCORES] O(N) + O(log M) 集差集计算直接返回（Redis 7.0+）。
ZSCAN ZSCAN key cursor [MATCH pattern] [COUNT count] O(1) 每次调用 读增量迭代有序集合。
ZRANDMEMBER ZRANDMEMBER key [count [WITHSCORES]] O(N) count 读随机返回元素（Redis 6.2+）。
ZMSORE ZMSORE key member [member ...] O(1) 每个元素 读批量获取元素分数（Redis 7.0+）。

5. Hash（哈希） 写 读 删

类似 Java 的 HashMap<String, String>，适合存储对象（如用户信息）。内部使用压缩列表或哈希表，小数据量时节省内存。
命令语法复杂度说明
HSET HSET key field value [field value ...] O(1) 每个 field 写设置一个或多个 field 的值。
HSETNX HSETNX key field value O(1) 写仅当 field 不存在时设置值。
HGET HGET key field O(1) 读获取指定 field 的值。
HMSET HMSET key field value [field value ...] O(1) 每个 field 写同 HSET（旧版，未来可能废弃）。
HMGET HMGET key field [field ...] O(1) 每个 field 读批量获取多个 field 的值。
HGETALL HGETALL key O(N) 读返回所有 field-value 对（慎用于大 Hash）。
HINCRBY HINCRBY key field increment O(1) 写原子增加 field 的整数值。
HINCRBYFLOAT HINCRBYFLOAT key field increment O(1) 写原子增加 field 的浮点数值。
HDEL HDEL key field [field ...] O(1) 每个 field 删删除一个或多个 field。
HEXISTS HEXISTS key field O(1) 读判断 field 是否存在。
HLEN HLEN key O(1) 读获取所有 field 的数量。
HKEYS HKEYS key O(N) 读返回所有 field 名。
HVALS HVALS key O(N) 读返回所有 value。
HSTRLEN HSTRLEN key field O(1) 读返回 field 对应值的字符串长度。
HRANDFIELD HRANDFIELD key [count [WITHVALUES]] O(N) count 读随机返回一个或多个 field（Redis 6.2+）。
HSCAN HSCAN key cursor [MATCH pattern] [COUNT count] O(1) 每次调用 读增量迭代 Hash 的 field-value 对。
说明： 标签含义 —— 写 写入/修改， 读 读取/查询， 删 删除， 阻 阻塞， 集 集合运算。 复杂度中的 N 为集合元素数量，M 为返回/操作元素数量。
