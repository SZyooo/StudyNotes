# CH01. 关系模型介绍

## 一、关系数据库的结构

关系数据库由**表**（table）的集合构成，每个表有唯一的名字。

表中的一行代表了一组值之间的**联系**。由于一个表就是这种联系的集合，**表**这个概念与数学上的**关系**概念是密切相关的。

在数学术语中，**元组**（tuple）是一组值的序列；若 n 个值之间存在某种联系，则可用一个 **n 元组**（n-tuple）来表示。

在关系模型的术语中：
- **关系**（relation）用来表示表
- **元组**（tuple）用来指代行
- **属性**（attribute）用来指代列

**关系实例**（relation instance）指一个关系的特定实例，即所包含的一组特定行。

关系是元组的集合，因此元组在关系中出现的顺序无关紧要。

对于关系的每个属性，都存在一个允许取值的集合，称为**域**（domain）。

**要求：对所有关系 r 而言，r 的所有属性的域都是原子的**。例如，属性"号码"若存储一个老师的多个号码，则不是原子的。

**空值**（null）表示值未知或不存在。

## 二、数据库模式

需要区分**关系模式**（relation schema）、**关系实例**（relation instance）和**关系**（relation）三者的概念。

| 概念 | 类比 |
|------|------|
| **关系模式** | 程序设计语言中的**类型定义** |
| **关系** | 程序设计语言中的**变量** |
| **关系实例** | 变量在某个时刻的**值** |

关系模式主要包含：
- 属性序列
- 各属性对应的域

关系模式的典型表达形式：

```
department(dept_name, building, budget)
```

关系实例则是一组符合关系模式的元组集合。

## 三、码

一个元组的属性值必须能够唯一区分元组。即**一个关系中没有两个元组在所有属性上的取值都相同**。

### 3.1 超码（superkey）

**超码是一个或多个属性的集合，这些属性的组合可以使我们在一个关系中唯一地标识一个元组。**

### 3.2 候选码（candidate key）

超码可能包含无关紧要的冗余属性。候选码是**最小的超码**：其任意真子集都不能成为超码。

### 3.3 主码（primary key）

主码是数据库设计者选中的、主要用来在一个关系中区分不同元组的候选码。

### 3.4 外码（foreign key）

一个关系模式 r1 可能在其属性中包含另一个关系模式 r2 的主码。这个属性在 r1 中称为参照 r2 的**外码**。

- r1：**参照关系**（referencing relation）
- r2：**被参照关系**（referenced relation）

#### 3.4.1 参照完整性约束

外码约束与参照完整性约束容易混淆，二者的区别如下：

假设 r1 是参照关系，r2 是被参照关系，外码为 FK：

- **外码约束**：从 r1 中任取一个元组 t1，若 t1.FK 不为 null，则必然在 r2 中存在元组 t2，满足 t1.FK = t2.FK。
- **参照完整性约束**：r1 中任意元组在特定属性上的取值，必然等于 r2 中某个元组在特定属性上的取值。

**示例**：假设某门课分段授课，每阶段由一位老师授课。要求 course 中某个元组 `(course_id, sec_id, semester, year)` 必须在 teaches 关系中出现。但该属性组合并非 teaches 的主码，因此这不是外码约束（反过来，可声明从 teaches 到 course 的外码约束）。

## 四、关系查询语言

查询语言（query language）是用户用来从数据库中请求获取信息的语言。

查询语言可分为两类：

- **过程化语言**（procedural language）：用户指导系统对数据库执行一系列操作以计算出所需结果。
- **非过程化语言**（nonprocedural language）：用户只需描述所需信息，无需指定操作步骤。

实际使用的查询语言通常兼具两种方式，SQL 就是被广泛使用的查询语言之一。

## 五、关系运算

所有过程化查询语言都提供一组运算，这些运算施加于单个或一对关系上，且满足一个重要的性质：**运算结果总是单个关系**。

| 运算 | 说明 |
|------|------|
| **选择**（σ） | 从单个关系中选出满足特定谓词的元组（结果是原关系的子集） |
| **投影**（Π） | 从关系中选出特定的列，并去除重复元组 |
| **自然连接**（⋈） | 将两个关系中相同属性取值相同的元组合并 |
| **笛卡尔积**（×） | 将两个关系的所有元组进行拼接，无匹配条件 |
| **集合运算** | 关系是元组的集合，因此可进行并、交、差等集合运算 |

### 关系代数形式化表达

| 运算 | 符号 | 说明 |
|------|------|------|
| 选择 | σ<sub>谓词</sub>(关系) | 返回满足谓词的元组 |
| 投影 | Π<sub>属性列表</sub>(关系) | 输出指定属性，去重 |
| 自然连接 | 关系₁ ⋈ 关系₂ | 对两个关系进行自然连接 |
