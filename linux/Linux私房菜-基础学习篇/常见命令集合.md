`ls`: 查看路径文件，默认隐藏“.”开头的文件
> `ll`这个命令是`ls -l`的缩写

`date`：查看/设置日期

`cal`：显示日历

`bc`：基本的计算器

`man`：查找系统手册

`info`：查看系统手册

`who`：查看当前谁在线

`netstat`：查看网络状态

`ps`：查看进程

`sync`：内存数据写入磁盘。应该在关机调用

`shutdown`：关机

`reboot`/`halt`/`poweroff`

`cd` : 切换目录

`pwd` : 显示当前目录

`mkdir` : 建立一个新目录

`rmdir` : 删除一个空目录

`cp` : 拷贝文件/目录

`rm` : 删除文件/目录

`mv` : 移动、重命名、交换文件或者目录

`cat` : 从第一行开始显示内容

`tac` : 从最后一行开始显示（`tac`是`cat`的倒写）

`nl`  : 显示文件内容，同时显示行号

`more`: 一页一页地显示文件内容

`less` : 和`more`类似，但是支持向下翻页

`head` : 只显示文件前面几行

`tail` : 只显示文件结尾几行

`od`  : 以二进制地方式读取文件内容

`touch` : 新建空文件或者修改文件的各项时间属性

`umask` : 查看/设置当前用户的umask

`passwd` : 设置账户密码

`chattr` : 设置文件的隐藏属性

`lsattr` : 查看文件的隐藏属性

`file` : 查看文件类型

`which` : 根据PATH环境变量规范的路径，查找可执行文件的文件名字

`whereis` : 在`/usr/bin`、`/usr/share/man`路径查找指定文件

`locate` : 模糊搜索文件

`updatedb` : 更新`locate`命令所使用的数据库
