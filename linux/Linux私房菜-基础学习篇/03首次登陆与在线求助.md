# 首次登陆与在线求助

## 一、首次登陆系统

### 1.1 GNOME的操作与注销

X Windows是一套Unix系统下的GUI**协议**，主要包含两个方面：

- X 服务器
- X 客户端

X客户端通过接口协议请求服务器绘制图形，X服务器处理请求调用显卡进行实际绘制。同时，X服务器还会监听键盘鼠标事件，如果发生的话则会通知客户端。

而GNOME则是运行在X上的一套桌面环境。它会基于X进行窗口的绘制以及最大最小化控制。

我们可以通过默认按键`Control+Alt+Backspace`来重启X服务，这样的话桌我们可以重新进入登陆画面。这样做的主要目的是为了处理显示错误等情况。

#### 1.1.1 tty1-tty6

Linux默认提供了6个独立的纯文本虚拟控制台，编号从tty1到tty6。

> tty的意思是Teletypewriter

我们可以通过按键`ctrl+alt+F1-F6`来在它们之间切换。

如果操作系统带有图形界面的话（例如UBuntu），则图形界面会默认占用tty1或者tty2。

### 1.2 命令行模式命令的执行

#### 1.2.1 命令的结构

所有命令都遵循以下结构：

```bash
command [-/+options] parameter1 parameter2...
```
如果一行命令太长，可以使用`\`来转义回车换行。

#### 1.2.2 重要的快捷键

- `Tab`:补全。两下的话列出所有补全
- `Ctrl-c`:终止程序
- `Ctrl-d`:
  - 发送键盘输入EOF信号
  - 表示输入`exit`
- `Shift + [PageUP|PageDown]`:在命令行翻页

## 二、在线求助man page和info page

### 2.1 `--help`选项

绝大多数命令在设计的时候都提供了`--help`选项，用来打印简单的命令使用帮助。

### 2.2 man page

`man`命令是用来查看某个命令的操作说明的。

```
man [options] [section] [page]
```

> `man`代表的是“manual”的意思。

`man`是系统手册页。每一个传递给`man`命令的`page`参数一般都是程序（例如`ls`）、函数（例如`printf`）等名称。关于这些参数的manual page就会被搜索并且展示出来。

Unix/Linux系统的标准下，会将page按照不同的分类归档到不同的<font color=#0F15F7>section</font>中，这样的话不会出现名称冲突。例如`printf`既是shell命令也是标准库函数，在用户命令<font color=#0F15F7>section</font>（1）下面和库函数（3）下面都有关于`printf`的page。

标准规定了以下的不同<font color=#0F15F7>section</font>：

|<font color=#0F15F7>section</font> no.|含义|
|:-:|:-|
|1|可执行程序或者shell命令|
|2|内核调用system call|
|3|系统库|
|4|特殊文件，在路径`/dev`下找到的文件|
|5|文件格式和规范，例如`/etc/passwd`文件的格式说明|
|6|游戏|
|7|杂项|
|8|root可执行的命令|
|9|非标准的内核例程|

如果给定了`section`参数，则`man`只会搜索在该<font color=#0F15F7>section</font>的page。默认行为是在所有的<font color=#0F15F7>section</font>中搜索，展示找到的第一个page。

我们可以使用`-a`参数让`man`展示一个名字的所有page。

一个manual page会包含多个小结（section）。

> 注意，这里的section和前面所讲的<font color=#0F15F7>section</font>是两个不同的东西。page分类的<font color=#0F15F7>section</font>我都用了特殊颜色字体。

这些小结包括：

- NAME
- SYNOPSIS（大纲）
- CONFIGURATION
- DESCRIPTION
- OPTIONS
- EXIT STATUS
- RETURN VALUE
- ERRORS
- ENVIRONMENT
- FILES
- VERSIONS
- CONFORMING TO（遵循的标准或者规范）
- NOTES
- BUGS
- EXAMPLE
- AUTHORS
- SEE ALSO

在man命令下，可以使用下面的快捷键：

|按键|作用|
|:-|:-|
|空格|向下翻一页|
|Page Down|向下翻一页|
|Page Up|向上翻一页|
|Home|翻到第一页|
|End|去最后一页|
|/string|向后搜索string|
|?string|向前搜索string|
|n/N|跳转到下一个/前一个搜索结果|
|q|退出|

man查找的文件一般放在`/usr/share/man`下面。我们可以通过修改`/etc/man_db.conf`来修改这个搜索路径。

#### 2.2.1 `whatis`和`apropos`
每个page的`NAME`section中都有关于该命令的简短说明。一般格式是：

```
NAME
    whatis - display manual page descriptiosn
```
`-`后面跟的就是简短说明。

我们可以使用下面两个命令来“模糊”查找包含指定命令的page的简短说明。

```bash
whatis [name]
```
搜索所有page的`NAME`小节，如果名字**完整匹配** 指定的`name`，则展示该page的简短说明


```bash
apropos [keyword]
```
搜索所有page的`NAME`和`DESCRIPTION`小节，在其中查找指定的`keyword`。如果存在该`keyword`，则展示该page的简短说明。

这两个命令的执行需要whatis数据库，这个数据库可以在root下执行`mandb`命令来构建。

`man`命令使用两个参数来实现这两个命令一样的效果：

- `man -f` - `whatis`
- `man -k` - `apropos`

### 2.3 info page

info page和man page类似，但是组织方法稍微有点不同：

info page将文件数据拆成一个个的小段落，并且每个段落都用独立的页面来编写；不同页面之间支持“超链接”跳转；每个独立的页面被称为“节点”。

node是在File内部的；node之间构成一颗节点树，可以通过快捷键进行导航，例如`p`/`n`在同层的节点之间进行跳转，`U`跳转到上一层节点。我们使用info命令之后，进入info阅读界面，可以按下`H`查看常用快捷键，或者直接运行`info info`来查看关于`info`的详细文档。

info命令打开的文档一般放在`/usr/share/info`路径下。

### 2.4 其他文档

并不是所有程序或者工具都提供了man或者info文档，这个时候我们可以进入到路径`/usr/share/doc/`下面查找文档。

## 三、如何关机

首先要明确的是：<font color=#FF0000> 不能随便关机 </font>。这是因为Linux默认是多人环境。也就是说可能除了当前用户，还有其他用户当前登陆了机器正在操作。因此，关机之前我们应该使用`who`命令查看以下当前有谁在线。

### 3.1 数据写入

处于性能考虑，很多数据都不会立即写入磁盘。因此如果我们直接关机，有可能数据没有写入磁盘系统就结束了。

因此我们应该在关机之前调用`sync`命令来让linux将内存内尚未写入磁盘的数据更新到磁盘上。

### 3.2 关机

如果我们是直接使用物理机器通过tty1-tty6操作，则无论是哪个用户，都能通过`shutdown`命令来直接关机。

`shutdown`命令不一定会直接关机，也可以重启或者指定关机时间；或者干脆不关机，而是向其他用户发送一条警告信息：

```bash
shutdown [-krhc] [time] [warning info]
```

- `-k`  :不关机，只是将`warning info`发送出去
- `-r`  :将系统的服务停掉之后重新启动
- `-h`  :将系统的服务停掉之后立即或者在指定时间关机
- `-c`  :取消正在进行的shutdown命令
