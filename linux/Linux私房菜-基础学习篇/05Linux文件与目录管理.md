# Linux文件与目录管理

> <font color="RED">下面列出的所有命令直接使用`man`查询用法</font>

## 一、目录相关操作

### 2.1 常见目录

首先我们应该记住下面这些特殊的目录：

- `.` : 当前目录
- `..`: 前一级目录
- `-` : 前一个工作目录
- `~` : 当前用户的家目录
- `~account` : account用户的家目录

> 根目录的`..`和`.`是同一个目录，都是自己

### 2.2、执行文件路径的环境变量 `$PATH`

有点像Windows下的环境变量，Linux下是`$PATH`变量。我们可以使用`echo`命令来打印它的值。

最好不要将`.`加入到`PATH`中，有一个很重要的原因是安全：假设有用户在`/tmp`目录中放置一个名为`ls`的可执行文件，有人在`/tmp`下面用root身份下意识执行了一下`ls`，可能就执行了这个第三方植入的`ls`程序了。

## 二、文件与目录管理

### 2.1 文件与目录查看

我们主要使用`ls`命令来查看命令。因为`ls -l`用的比较多，所以很多Linux发行办利用Bash shell的alias将`ll`设计为`ls -l`，即我们可以通过命令`ll`达到`ls -l`一样的效果。

### 2.2 赋值、删除和移动

#### 2.2.1 复制文件和目录

使用`cp`命令来复制文件和目录。

默认情况下，`cp`命令复制的文件拥有者会变为执行该命令的用户，我们可以通过`-p`选项来复制源文件的属性（权限、用户和时间）。

#### 2.2.2 删除文件或目录

使用`rm`来删除文件或者目录。常用的参数有：

- `-f` : 强制删除
- `-i` : 交互模式
- `-r` : 递归删除

另外我们可以借助通配符`*`来进行模糊匹配。 

另外，因为root用户拥有删除任意文件的权限，因此root用户下执行这个命令会默认添加`-i`参数。

#### 2.2.3 移动目录文件或者重命名

使用`mv`来移动文件或者目录，如果是“移动”到同一个文件夹，则作用相当于重命名。

常用的参数有：

- `-f` : 强制删除
- `-i` : 交互式，每个文件都会询问
- `-u` : 只有当文件已经存在，并且源文件比较新，才会更新（update）

### 2.3 获取路径的文件名和目录名

使用`basename`获取路径中的文件名字；使用`dirname`获取路径中的目录名字。


## 三、文件内容查看

### 3.1 命令列表

- `cat` : 从第一行开始显示内容
- `tac` : 从最后一行开始显示（`tac`是`cat`的倒写）
- `nl`  : 显示文件内容，同时显示行号
- `more`: 一页一页地显示文件内容
- `less` : 和`more`类似，但是支持向下翻页
- `head` : 只显示文件前面几行
- `tail` : 只显示文件结尾几行
- `od`  : 以二进制地方式读取文件内容

### 3.2 直接查看文件内容

#### 3.2.1 `cat`

`cat`代表的含义是“concatenate”。常用的选线有：

- `-A` : 相当于`-vET`的整合选项
- `-b` : 列出行号。仅当非空白行显示
- `-E` : 将结尾的换行符用`$`显示出来
- `-n` : 打印行号，联通空白行也会有行号
- `-T` : 将`tab`符号以`^I`的形式打印出来
- `-v` : 列出一些看不出来的特殊字符
  
#### 3.2.2 `tac`

和`cat`相反，这个命令是将文件的内容从最后一行倒过来打印。

#### 3.2.3 `nl`

这个命令会打印文件内容同时显示行号。比较特殊的是它支持对行号宽度、位置进行设置：

- `-b` : 指定行号打印方式，有两种：
    `-b a`: 表示无论是否是空行都打印
    `-b t`: 如果有空行，则跳过该空行不打印行号（默认）
- `-n` : 列出来行号表示的方法，主要有三种：
    `-n ln` : 行号在栏位最左方显示
    `-n rn` : 行号在栏位最右方显示，加0
    `-n rz` : 行号在栏位最右方显示，不加0
- `-w` : 行号栏位的宽度
  
> 所谓的“栏位”就是打印数字的位置，固定在左侧。可以调整宽度，如果宽度大于实际数值宽度，则可以指定数值是对齐到栏位的左右边。

### 3.3 可翻页查看

前面的`nl`、`cat`等命令的作用是将文件内容完全输出到终端，如果文件太大的话，会让终端一次性输出非常多的内容。我们可以使用`more`或者`less`来替代。

#### 3.3.1 `more`

这个命令的作用是先打印一屏幕的内容，然后允许我们进行**向后**翻页：

- 空格键：向下翻一页
- Enter：向下翻一行
- /字符串：在显示的内容中搜索指定字符串
- :f ：立即显示文件名以及目前显示的文件行数
- q：立即离开more
- b或者ctrl+b：往回翻页
  
#### 3.3.2 `less`

和`more`类似，但是提供了更多的功能。常用的功能有：

- 空格键：向下翻动一页
- [pagedown] ：向下翻动一页
- [pageup] ：向上翻动一页
- /字符串 ：向下查找字符串
- ?字符串：向上查找字符串
- n：重复上一次查找
- N：反向重复上一次查找
- g：前进到这个数据的第一行
- G：跳转到这个数据的最后一行
- q：离开less

### 3.4 数据截取

#### 3.4.1 `head`

这个命令仅仅打印文件的前面指定行数：

`-n x`：打印前面的x行。如果x是负数，则除掉结尾的x行，打印前面所有行

#### 3.4.2 `tail`

和`head`功能相反，打印目标文件的结尾行数。支持的参数有：

`-n x`：指打印结尾n行；如果添加了`+`号，则表示打印除去前面x行剩下的所有内容
`-f` ：持续刷新显示文件内容，这样文件如果在被编辑的话可以立即查看最新内容

> 如果我们希望打印指定[n,m]行，我们该怎么做？答案是利用管道：`head -n m file | tail -n n`


### 3.5 非文本文件

我们使用`od`来查看非文本文件。命令常用的参数有：

`-t [TYPE]`。

其中，`[TYPE]`用来指定输出方式，主要有：

- a：利用默认字符输出
- c：利用ASCII输出
- d[SIZE]：利用10进制输出，每个整数占据SIZE字节
- f[SIZE]：利用浮点数值来输出，每个数占据SIZE字节
- o[SIZE]：利用八进制来输出，每个整数占据SIZE字节
- x[SIZE]：利用十六进制来输出，每个整数占据SIZE字节

更多使用查询`man`。

### 3.6 修改文件时间或者创建新文件

我们使用`touch`来修改文件时间或者创建新的文件。

Linux下每个文件都会有多个时间属性，其中主要有3个变动时间：

- 修改时间（modification time，`mtime`）：当文件内容发生变化的时候会更新这个时间
- 状态时间（status time，`ctime`）：当文件的状态发生变化的时候会更新这个时间。文件状态包括权限、属性等
- 读取时间（access time，`atime`）：当读取这个文件的时候会更新这个时间

> 在`ls`命令中我们可以在`--time=atime`这个选项中指定展示上面三个时间中的哪一个。默认情况下`ls`展示的是`mtime`。

我们可以使用`touch`来修改文件的时间：

`touch [-acdmt] file`

其中常用的选项有：

- `a`：仅仅修改atime
- `c`：仅仅修改ctime，如果不存在**不会**创建新的文件
- `d`：`--date="日期"`，指定时间
- `m`：仅仅修改mtime
- `t`：`-t [YYYYMMDDhhmm]`，指定时间

## 四、文件与目录的默认权限与隐藏权限

### 4.1 文件默认权限

在一个用户创建文件或者目录之后，文件或者目录的默认权限是什么呢？指定这个属性的是`umask`。

`umask`并不会直接指定文件或者目录权限，而是指定创建的文件或者目录**不具备**的权限。

在默认情况下，用户创建的文件不会具有可执行权限，因此，最大的权限值为666(rw-rw-rw)；如果用户创建的是目录的话，因为对于目录来说x权限至关重要，因此默认情况下目录创建出来之后的权限最大值为777(rwxrwxrwx)。

这个时候`umask`就发挥作用了：在上面的最大权限之上，减去`umask`，得到的就是文件或者目录的权限。

例如，假设我们指定`umask`=022，则新建文件和目录的权限为：

- 建立文件：(rw-rw-rw-) - (----w--w-) = (rw-r--r--)=644
- 建立目录：(rwxrwxrwx) - (----w--w-) = (rwxr-xr-x) =755

### 4.2 文件的隐藏属性

除了基本的r、w、x属性外，在Linux传统的**ext2**，**ext3**，**ext4**文件系统下，我们还可以设置文件的其他隐藏属性。我们使用`chattr`来设置，使用`lsattr`来查看。

> 在CentOS 7.x当中利用xfs作为默认文件系统，但是xfs没有支持所有的`chattr`的参数

#### 4.2.1 `chattr`

这个命令是用来配置文件的隐藏属性的：

```bash
chattr [+-=] [ASacdistu] 文件或者目录名称
```

其中，

- `+`：表示在原有属性的基础上增加属性
- `-`：表示在原有属性的基础上删除属性
- `=`：表示直接重新设置属性
  
常用属性包括：

- `A`：设置了这个属性之后，我们存取该文件的时候，它的存取时间atime不会被修改
- `S`：一般来说文件时非同步写入磁盘的（先写入内存，然后再写入磁盘），但是加上这个属性之后，任何修改都会立即同步到磁盘中
- `a`：当设置这个属性之后，文件只能增加数据，不能删除也不能修改数据
- `c`：设置这个属性之后，会自动将这个文件进行压缩，在读取时则会自动解压；存储的时候也会自动先压缩再存储
- `d`：当dump程序执行的时候，设置这个属性可以避免这个文件被dump文件备份
- `i`：设置这个属性之后，可以让一个文件不能被删除、改名、设置链接也无法写入或者新增数据。只有root可以设置此属性
- `s`：设置这个属性之后，文件如果被删除则直接从磁盘删除，会导致误删文件完全无法恢复
- `u`：和`s`相反，如果文件被删除了，则内容其实还存在在磁盘上，可以用来恢复文件

其中，最常见的时`+a`属性和`+i`属性，前者可以用来设置日志文件，这样可以保证日志文件；后者可以给予文件最高的安全保护。

#### 4.2.2 `lsattr`

这个命令用来显示文件的隐藏属性

```bash
lsattr [-adR] 文件或者目录
```

其中常见选项有：

`a`：将隐藏文件的属性也显示出来
`d`：如果接的时目录，则仅列出目录本身而非目录内的文件名
`R`：连同子目录的数据也一并列出来

### 4.3 文件的特殊权限：SUID、SGID、SBIT

如果我们查看`/tmp`和`/usr/bin/passwd`两个目录的权限的话，我们会发现`/tmp`目录有一个权限是't'，而`/usr/bin/passwd`有一个权限是's'。这两个权限与系统的账号、系统的进程管理相关。

#### 4.3.1 Set UID

当s出现在文件**拥有者**的x权限上的时候，此时的作用被称为“Set UID”，或者被称为“SUID”的特殊权限。SUID具有以下特点和功能：

- SUID仅仅对二进制程序文件有效
- 执行者对于该程序需要具有x的可执行权限
- 本权限仅仅在该程序执行过程中有效
- 执行者在执行过程中将临时具有该程序拥有者的权限

例如对于文件`/etc/shadow`，它内部记录着不同用户的密码，它的权限是'rw-r-----'，除了root用户外其他用户至多可以读取，不可以写入；而`/usr/bin/passwd`程序可以用来设置当前用户的密码，显然需要写入到`/etc/shadow`，但是任何用户都可以通过这个程序设置本账户的密码。按道理来说这是行不通的。

但是因为`/usr/bin/passwd`设置SUID属性，则意味着任何可执行者在执行它的时候都会临时获取它拥有者（即root）的权限，也即意味着可以写入`/etc/shadow`。

#### 4.3.2 Set GID

如果s出现在**用户组**的x位置，则成为Set GID，或者说该文件具有SGID属性。

与SUID不同的是，SGID可以支持对目录设置。

**如果是文件**
对于文件而言，SGID属性带来的功能为：

- SGID仅仅对二进制程序有用
- 程序执行者对于该程序来说必须具备x的权限
- 执行者在执行该程序的过程中临时具有该程序所属用户组的权限

**如果是目录**

当SGID被设置给一个目录的时候，带来的功能为：

- 用户若对此目录具有r和x的权限，该用户能够进入该目录
- 用户在此目录下的有效用户组将临时变为该目录的用户组

#### 4.3.3 Sticky Bit

Sticky Bit(SBIT，粘滞位)目前仅仅针对目录有效，作用是：

- 当用户对于此目录具有w、x权限，则具有写入的权限
- 当用户在该目录下建立文件或者目录时，仅有自己和root才有权力删除该文件
  
例如如果用户甲对于目录A而言是用户组或者其他人身份，并且拥有w权限，则意味着他能够删除、更名、移动该目录中的文件或者目录，即使这些目录或者文件是其他人创建的。不过，如果这个路径被添加了SBIT属性，则甲用户只能删除、更名、移动自己创建的文件。

#### 4.3.4 SUID/SGID/SBIT权限设置

我们可以通过3个数字来设置[拥有者-用户组-其他人]设置三类角色的权限，如果想要设置SUID/SGID/SBIT权限的话，我们增加一个数字即可：

- SUID: 4
- SGID: 2
- SBIT: 1

例如 `4755`表示在`755`的基础上增加SUID属性。
另外，我们也可以分别通过`u+s`设置SUID，`g+s`设置SGID以及`o+t`设置SBIT。

另外，我们发现三个权限都有一个基础，就是都需要用户对文件或者文档具有x权限。如果我们给一个文件或者路径添加SUID/SGID/SBIT权限的时候该文件或者路径没有x权限，则对应的权限位置会用大写的S/T来替代小写的s/t，表示这是一个空的s/t权限：原本的用户/用户组都没有x权限，即使添加了S/T，实际上也没有实际权限。

## 五、命令与文件的查找

### 5.1 脚本文件的查找

#### 5.1.1 `which`

这个命令用来查找可执行文件的路径。支持`-a`选项表示将所有查找结果都找出来，而不是仅仅找第一个。

### 5.2 文件的查找

#### 5.2.1 `whereis`

这个命令会在特定的目录中查找指定文件。常用的参数有：

`-l` : 列出`whereis`会去查找的目录
`-b` : 只查找二进制格式的文件
`-m` : 只找在说明文件manual路径下的文件
`-s` : 只查找源文件
`-u` : 查找不在上述三个项目中的其他特殊文件

这个命令因为只会在指定的路径下（`/bin`、`/sbin`、`usr/share/man`）下查找，所以查询速度会比较快。

#### 5.2.2 `locate`/`updatedb`

`locate`命令也是用来查找文件的，支持以下参数：

`-i` : 忽略大小写
`-c` : 不输出文件名字，仅仅计算找到的文件数量
`-l` : 指定输出行数
`-S` : 输出`locate`命令所使用的数据库文件的相关信息
`-r` : 后面可接正则表达式的显示方式

命令支持模糊搜索，只要文件名字包含指定的参数名字，就认为是匹配的。

这个命令执行起来比较快，因为是基于一个现存的数据库来查找的。这个数据库更新的频率不一定，可能是一天一次。我们可以通过`updatedb`命令来手动更新。

#### 5.2.3 `find`

```bash
find [PATH] [option] [action]
```

##### 与时间有关的选项

- `-mtime n` : 在n天之前的一天之内被修改过内容的文件
- `-mtime +n` : 列出在n天之前（不含n天本身）被修改过内容的文件
- `-mtime -n` : 列出在n天之内（含n天本身）被修改过内容的文件
- `-newer file` : 列出比`file`还要新的文件

```bash
find / -mtime 0 #查找现在开始24小时之前被修改过的文件
find /etc -newer /etc/passwd #查找/etc路径下比/etc/passwd更新的文件
```
