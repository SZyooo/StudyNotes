# 空基类优化

C++标准规定空类型对象必须能够被寻址。但是，如果空类型是基类的话，则可以被优化为空对象：

```c
struct E{};

struct A : E
{
    int x;
};

struct B
{
    E e;
    int x;
}

```

上面的定义中，`sizeof(A)=4`，`sizeof(B)=8`。这是因为A类型的基类是一个空类型，所以被优化为了空对象；而B中，需要对`B::e`成员进行寻址，所以成员`e`必须具有一个字节。


但是C++明确要求：**<font color="red">如果第一个非`static`成员的类型和空基类的类型一致，则禁止EBO<font>**

原因很简单：**必须保证两个不同类型的对象的地址不一样**

```c
struct B: E
{
    E e;
    int x;
};
B b;
```

上面类型中，`sizeof(B)`仍然是8，但是`&b`是不等于`&b.e`的，并且`&b.e = &b + 1`。这是因为这个时候基类对象不能被优化，因此占据着一个字节的地址。

> 不过这段代码运行在MSVC的话会发现`&b.e==&b`，这是MSVC的一个BUG
