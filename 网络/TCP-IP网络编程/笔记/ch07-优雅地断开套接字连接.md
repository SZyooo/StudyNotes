# 优雅地断开套接字连接

## 一、TCP的半关闭

### 1.1 单方面关闭

前面介绍的函数`close`作用是彻底关闭TCP连接。这意味着TCP两个方向的连接都会被关闭。

### 1.2 套接字和流

两台主机通过TCP套接字建立连接之后，是在两者之间建立了两条单向的数据流：

- 输出流
- 输入流

我们可以选择单独关闭其中的一个流，而非使用`close`直接关闭两个流。


### 1.3 `shutdown`函数

`shutdown`函数的作用就是关闭单向流：

```c
#include <sys/socket.h>

int                 //成功返回0，失败返回-1
shutdown(           
    int sock,       //需要断开连接的套接字描述符
    int howto       //断开哪个流？
)
```

其中，`howto`参数支持下面三个选项：

- `SHUT_RD`:关闭输入流
- `SHUT_WR`:关闭输出流
- `SHUT_RDWR`:关闭两个流

### 1.4 为啥需要半关闭

理由很简单：某一方需要关闭输出流的时候，并不知道对面是否已经发送完了数据；如果自己发送完了就暴力关闭，则有可能对方发送的数据还没有完全送到。

### 1.5 如何关闭

和大多数流一样：如果往流中写入`EOF`，即意味着关闭了流。因此，`shutdown`和`close`都会向输出流中写入`EOF`。
