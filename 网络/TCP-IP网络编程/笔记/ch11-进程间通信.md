# 进程间通信

## 一、管道(Pipe)

### 1.1 创建管道

两个进程之间可以通过管道进行通信。管道和套接字一样属于操作系统内核资源。创建管道的函数：

```C
#include <unistd.h>

int                     //成功返回0，失败返回-1
pipe(                   
    int filedes[2]      //filedes[0]:接收数据的文件描述符 filedes[1]:发送数据的文件描述符
);
```

父进程通过这个函数创建管道了之后，通过`fork`拷贝给子进程，然后通过该管道和子进程通信。

> 管道的大小是系统属性，默认为64KB。可以通过`fcntl`获取

### 1.2 利用单管道进行进程间通信的问题

数据进入管道之后变成无主数据，谁先调用`read`谁先获取到数据；如果一个进程写入之后立即读取的话，则可能将自己写入的数据读出，导致等待读取它写入数据的进程阻塞在`read`上。


### 1.3 利用双管道进行进程间通信

直接创建两个管道分别负责双向的数据流动。
